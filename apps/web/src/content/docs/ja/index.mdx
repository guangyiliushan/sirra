### コンテンツタイプ

本ナレッジベースのコンテンツは以下の三種類に分類されます：

- **ドキュメント**：体系的な技術文書とリファレンスマニュアル。順を追って読むのに適した完全な資料
- **ノート**：学習過程での記録とまとめ。個人の理解と注釈を含む
- **知識ポイント**：独立した知識項目。素早く参照するのに適した短いコンテンツ
